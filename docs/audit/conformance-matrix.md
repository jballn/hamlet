## Detailed Findings Summary

### Remediation Summary for Audit Findings

#### Finding 10/01-01 (HIGH) — Production daemon entrypoint `serve_daemon` runs `FakeRuntime` and leaves background governor loops unspawned
- **Status:** **REMEDIATED**.
- **Fix:** In `crates/hamlet-daemon/src/local_api.rs:serve_daemon`, auto-detect rootless podman on `PATH` (falling back to `FakeRuntime` when podman is absent or `HAMLET_FORCE_FAKEAGENT=1`), construct `MayorEngine` with session recovery, wire `MayorEngine` into all wake sources (`ledger.with_wake`, `mail_router.with_mayor_mail`, `supervisor.set_crash_wake`, `freight_guard`, `webhook_service`, `spawn_ack_timeout_watch`), start `spawn_tree_watcher`, attach all 6 background event planes (`mailroute`, `decrees`, `freight`, `git_spool`, `deed`, `dispatch`), and wire graceful shutdown.
- **Verification:** `crates/hamlet-daemon/tests/local_api.rs:test_serve_daemon_governor_startup_and_plane_orchestration`.

#### Finding 10/01-02 (LOW) — Directory topology divergence: `census_git_archive` placed under `keep/census/archives/` instead of `keep/archives/`
- **Status:** **REMEDIATED**.
- **Fix:** In `crates/hamlet-core/src/tree.rs`, updated `census_git_archive` and added alias `git_archive` to return `keep/archives/git/<commission>/<uid>/` conforming to SPEC §2, with backward compatibility if legacy path exists. Updated ADR-0037 and `ledger.rs` references.
- **Verification:** `crates/hamlet-core/src/tree.rs` unit tests, `crates/hamlet-daemon/tests/git_mediation.rs`.

#### Finding 10/01-03 (LOW) — CLI verb behavior divergence: `hamlet mail read <uid>` without `<file>` delegates to listing summaries
- **Status:** **REMEDIATED**.
- **Fix:** Updated `crates/hamlet-cli/src/mail.rs:read` so that calling `hamlet mail read <uid>` without `<file>` fetches the latest message for that recipient slot, while `hamlet mail list` continues to list message summaries.
- **Verification:** `crates/hamlet-cli/tests/cli_integration.rs:test_mail_send_list_read_lifecycle`.
